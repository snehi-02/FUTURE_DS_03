# Task 3: Marketing Funnel & Conversion Performance Analysis

## Project Overview

This project analyzes e-commerce user behavior to understand product views, cart activity, purchases, and conversion performance using Python and Power BI.

## Tools Used

* Python
* Pandas
* Matplotlib
* Power BI
* Jupyter Notebook

## Key Findings

* Total events analyzed: 10,000
* Product view events: 9,805
* Sessions with product views: 2,449
* Sessions with views and cart activity: 60
* Sessions with views, cart activity, and purchases: 29
* View-to-cart rate: 2.45%
* Overall session conversion rate: 1.18%

## Recommendations

* Improve product pages with clear descriptions, images, prices, and customer reviews.
* Simplify the add-to-cart and checkout processes.
* Investigate possible reasons for cart abandonment.
* Study category and brand performance to identify opportunities for improvement.

## Data Limitation

This analysis uses the first 10,000 rows of an approximately 8.5 GB dataset. Results are preliminary and may not represent the complete dataset. Funnel metrics are based on event presence within sessions; event chronology has not been verified.

## Deliverables

* Python analysis notebook
* Power BI dashboard
* Dashboard screenshot
* Summary findings and recommendations
